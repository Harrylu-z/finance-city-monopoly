# 中国金融城 · 像素大富翁

> 一款以「中国金融都市圈」为舞台的像素风网页版大富翁（Monopoly 类）。
> 你与 3 位性格各异的 AI 玩家争夺金融机构经营权 —— 收购牌照、升级总部大楼、
> 收取管理费、穿越牛熊周期，直到成为这座金融城唯一的玩家。

**零构建 · 纯静态 · 原生 ES Modules** —— 克隆下来用 Python 起个服务器就能玩，
也可以一键丢到 GitHub Pages / Vercel / Netlify。

## 快速开始

### 环境要求

- **Python 3.8+**（用于本地静态服务器，零第三方依赖）
- 现代浏览器（Chrome / Edge / Firefox / Safari，需支持 ES Modules）

> 项目**不需要 Node.js**，也不需要任何构建步骤、npm 包或打包器。

### 运行

```bash
# 方式一：一键启动（自动打开浏览器）
python serve.py

# 方式二：指定端口
python serve.py 8080

# 方式三：不自动打开浏览器
python serve.py 8080 --no-browser
```

启动后访问终端提示的地址（默认 <http://127.0.0.1:8000/>）。

> **为什么不用 `python -m http.server`？**
> `serve.py` 额外做了三件事：
> 1. **双栈监听（IPv4 + IPv6）** —— 浏览器访问 `localhost` 时会先尝试 IPv6，
>    如果服务端只监听 IPv4，浏览器要等约 2 秒 TCP 超时才会回退，首屏极慢；
> 2. **显式 MIME 类型** —— 保证 `.js` 以 `text/javascript` 返回，ES Module 才能正常加载；
> 3. **多线程处理** —— 23 个模块并发加载时不会互相阻塞。

### 校验项目完整性

```bash
python tools/check-imports.py
```

会扫描 `src/` 下所有相对 `import` 路径，确认没有 404。

## 部署

项目是**纯静态站点**，产物就是仓库根目录，不需要编译。

### GitHub Pages

```bash
# 1. 在仓库设置里开启 Pages，Source 选 "Deploy from a branch"
#    Branch 选 main，目录选 / (root)

# 2. 如果你不想让 .py 文件跟着上线，可以加一个 .nojekyll
touch .nojekyll
```

或者用 Actions：

```yaml
# .github/workflows/deploy.yml
name: Deploy Pages
on:
  push: { branches: [main] }
permissions: { contents: read, pages: write, id-token: write }
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/configure-pages@v5
      - uses: actions/upload-pages-artifact@v3
        with:
          path: .
  deploy:
    needs: build
    runs-on: ubuntu-latest
    environment: { name: github-pages, url: ${{ steps.deployment.outputs.page_url }} }
    steps:
      - uses: actions/deploy-pages@v4
```

### Vercel

```bash
npm i -g vercel
vercel --prod
```

Vercel 会自动识别为静态站点（Framework Preset: **Other**），无需构建命令，输出目录填 `.`。

### Netlify

```bash
npm i -g netlify-cli
netlify deploy --prod --dir .
```

或直接在 Netlify UI 中把仓库目录设为发布目录。

### 本地预览已部署版本

```bash
python -m http.server 8000   # 任何静态服务器都行
```

## 玩法说明

### 基本循环

**掷骰 → 移动 → 结算 → 回合结束**

### 你的回合可以做什么

| 操作 | 按钮 | 说明 |
|---|---|---|
| 掷骰 | `掷 骰 子` | 1~3 颗骰子，点数累加；空格 / 回车也可触发 |
| 收购 | 落点弹窗 | 无主机构可用「战略入股」方式收购（文案内化为收购 30% 股权） |
| 升级 | `我的机构` | 把网点升级为支行 → 分行 → 总部 → 地标（**须再次踏足自有地块**） |
| 质押融资 | `质押融资` | 把机构抵押换取现金（文案内化为股权质押融资 / 资产证券化） |
| 赎回 | `我的机构` | 支付解押费赎回已质押机构 |
| 央行贷款 | 起点弹窗 | 绕圈经过起点后可选档位贷款（与质押融资相互独立） |
| 发行债券 | 再融资窗口弹窗 | 向其他玩家募资，需 **≥2 人认购**方能成立 |
| 结束回合 | `结束回合` | 交棒给下一位玩家 |

### 金融主题文案对照

| 大富翁原概念 | 本作包装 |
|---|---|
| 买地 | 收购经营权 / 战略入股（30% 股权） |
| 租金 | 管理费 / 牌照手续费收入 |
| 升级建筑 | 升级总部大楼 / 增设网点 / 扩表 |
| 抵押 | 股权质押融资 / 资产证券化 |
| 破产 | 爆仓清算 / 强制平仓 / 摘牌退市 |
| 掷骰子 | 行情骰 / 交易机会 |
| 起点奖金 | 货币发行 / 流动性投放补贴（+￥200） |

### 破产与清算

现金不足以支付时进入破产流程：机构股权按规则折价清算，角色离场，
回合轮转会**自动跳过**破产玩家。破产结算面板会展示清算明细。

### 游戏结束

只剩 1 名未破产玩家时结束，弹出胜利结算画面（含撒花特效 + 资产排行榜 + 分享入口）。

### 快捷键

| 键 | 作用 |
|---|---|
| `空格` / `Enter` | 掷骰 |
| `Esc` | 关闭当前弹窗 |

## 棋盘设计

**63 格 = 45 个普通机构格 + 4 个监管机构格 + 14 个特殊格。**

布局为 **9 列 × 7 行的非正方形环形棋盘**（`BOARD_SHAPE = { cols: 9, rows: 7 }`）。
63 可被 9 整除，每条边恰好 7 格，环形拓扑闭合无误差；
横向略宽的版式更适合宽屏 —— 单元格接近正方形，立绘与文字都不挤。

### 四大集团

| 集团 | 格数 | 配色 | 建筑形态 | 租金系数 |
|---|---|---|---|---|
| 银行集团 | 11 | 深墨蓝 | 低层、宽体、石材立面、圆弧顶 | ×1.00 |
| 券商集团 | 11 | 鎏金 | 高层、尖顶、玻璃幕墙 + 天线 | ×1.10 |
| 保险集团 | 11 | 玉青 | 中层方正、带穹顶 | ×0.95 |
| 资管集团 | 12 | 朱红 | 现代几何体量、极简线条 | ×1.05 |

### 集团内部的价格/租金梯度

每格机构有 5 个等级，**价格与租金严格递增**（自检会逐格校验）：

| 等级 | 名称 | 体积表现 |
|---|---|---|
| 0 | 网点级 | 最矮，细节最少 |
| 1 | 支行级 | 略高，多一层 |
| 2 | 分行级 | 中等高度，窗格更多 |
| 3 | 总部级 | 高层，完整幕墙 |
| 4 | 地标级 | 最高 + 顶部标志物 / 皇冠 |

集团内前 3 格低价小型机构 → 中段区域总部 → 后段全国性总部 → 末格行业标杆。

### 四大监管机构（可持有 · 不可升级）

监管格是**买断式经营权格**：占用大量现金，但**不能升级**（`maxLevel` 固定为 0），
持有后对**全局**生效，不只是给自己加成 —— 这是本作最硬核的一层设计。

| 索引 | 机构 | 买入价 | 全局效果 |
|---|---|---|---|
| 12 | 中国人民银行 | ￥3200 | **流动性投放**：持有者每圈开始额外获得 +￥80 |
| 25 | 中国证监会 | ￥3400 | **注册制便利**：全体玩家升级费用 −12% |
| 38 | 金融监管总局 | ￥3000 | **审慎约束**：全体玩家租金收入 −8% |
| 55 | 金融稳定委员会 | ￥3600 | **风险缓冲**：持有者触发陷阱格时罚金减免 50% |

> 监管机构采用**紫金配色 + 双描边**，与普通机构的单色边框一眼可辨；
> 建筑立绘使用专属徽记（梅花币章 / 盾形刻章 / 齿状圆章 / 天平）。

### 特殊格（14 个）

| 索引 | 名称 | 效果 |
|---|---|---|
| 0 | 起点 · 陆家嘴金融中心 | 每圈经过 +￥200 货币发行补贴，**并可申请央行贷款** |
| 13 | 清算所 · 互联互通 | 跳转到指定机构 |
| 26 | 地铁 · 通勤枢纽 | 选择前进 1 / 2 / 3 格 |
| 39 | 财经快讯 · 事件卡 | 抽一张中国金融风事件卡 |
| 40 | 合规成本 | 印花税 / 交易手续费 / 监管罚款 三选一（￥140 / ￥180 / ￥240） |
| 41 | **监管抽查 · 穿透检查** | ⚠️ 陷阱格：抽取监管处罚事件卡 |
| 42 | 慈善公益捐赠 | 扣现金 ￥120 |
| 56 | 信用评级 · 展望调整 | 55% 上调 / 45% 下调自有机构租金收益 |
| 57 | 要素市场 · 大宗交易 | 大宗交易折溢价，现金双向流动 |
| 58 | 投资者路演 | 路演推介成功，资产估值提升 |

> **视觉区分**：陷阱格使用**斜向警示条纹**边框，普通特殊格用单色边框，
> 监管格用紫金双边框，三者在棋盘上一眼可辨。

### 陷阱格卡池（8 张）

现场检查罚没款、责令整改、评级下调、集中度超限、监管约谈、信息系统检查、窗口指导、流动性抽紧。
陷阱只影响踩中者本人；持有金稳会可将罚金减免 50%。

### 集团协同 Buff

持有同一集团机构数达到阈值即激活加成（**已质押的机构不计入**）：

| 持有数量 | 档位 | 租金加成 |
|---|---|---|
| 3 家 | 区域协同 | ×1.08 |
| 6 家 | 集团化经营 | ×1.16 |
| 9 家 | 生态圈龙头 | ×1.25 |

### 升级许可规则（再次踏足）

**只有再次踩到自己的地块，才能升级它。**

- 踩到自有地块 → 发放一张「升级许可」（`upgradePermits[cellIndex] = true`）
- 升级时校验许可，无许可则拒绝（「需再次踏足」）
- 升级成功后**立即消耗**该许可，一格一用

这让「铺网点」与「建高楼」成为两个独立节奏，避免一格升满后失去意义。

### 事件卡池（12 张）

监管发布新规、公司被举牌、获得过桥贷款、季报超预期、遭遇黑天鹅、接到一笔并购要约、
债券违约潮、央行降准释放流动性、北向资金大幅流入、IPO 审核提速、影子银行风险暴露、REITs 扩容获批。

部分事件带 `rentMult` 全局系数（影响所有机构租金），部分只影响自己。

### 市场周期

每 **3 圈**自动切换一次：

- **牛市** → 所有机构租金 **×1.20**
- **熊市** → 所有机构租金 **×0.80**

HUD 右上角与背景的像素 K 线灯带会同步显示当前周期。

## 融资工具

三种融资手段并行，各有代价，互不排斥：

### 1. 股权质押融资（随时可用）

把自有机构抵押换取现金（市值 × 0.55），赎回需付 12% 解押费。
代价是**租金收入停止**，且机构在被赎回前无法升级。

### 2. 央行贷款（起点绕圈后）

经过起点时弹出贷款选择，**利率与金额均可选**，共三档：

| 档位 | 额度 | 利率 | 到期应还 | 定位 |
|---|---|---|---|---|
| 支小再贷款 | ￥600 | 12% | ￥672 | 小额流动性支持，利率偏高 |
| 过桥资金 | ￥1200 | 18% | ￥1416 | 额度与利率均衡 |
| PSL 棚改 | ￥2000 | 24% | ￥2480 | 政策性工具，额度大但利率高 |

- 每圈**最多申请一次**
- 下一圈结束时自动扣款；若现金不足则触发**强制破产清算**
- 设计意图：地标级机构动辄 ￥6000+，靠现金滚存几乎不可能，
  必须用杠杆去够 —— 但杠杆有明确的到期日与成本

### 3. 债券发行（再融资窗口格）

落到「再融资窗口」后，可向**其他玩家**发行债券：

- 每人认购面值 ￥300，票面利率 **6%**
- 期限 **3 圈**，每圈结束时向认购人支付一次票息，到期兑付本金
- **必须 ≥2 人认购才算发行成功**（不足则发行失败）
- AI 会评估你的资产排名与自身现金储备来决定是否认购
  （排名越靠后信用越差，越难募到资）

> 发行方每圈需支付 `￥18 × 认购人数` 的票息；若中途现金不足同样会破产。
> 这让「借钱扩张」与「按时还本付息」形成真实的财务压力。

## AI 性格系统

3 位 AI 各自拥有不同性格档案（每局随机分配，尽量不重复）：

| 性格 | 现金留存 | 贪婪度 | 升级偏好 | 风险容忍 | 偏好集团 | 典型台词 |
|---|---|---|---|---|---|---|
| 激进型 | 10% | 1.35 | 中 | 0.85 | 券商 / 资管 | 「牌照就是印钞机，先拿下再说！」 |
| 保守型 | 42% | 0.65 | 低 | 0.25 | 银行 | 「不急，等估值合适了再说。」 |
| 囤房型 | 28% | 1.10 | 极低 | 0.45 | 全部（垄断同集团） | 「这一串我全包了，其他人靠边站。」 |
| 现金流型 | 34% | 0.92 | 极高 | 0.40 | 保险 | 「现金流为王，纸面繁荣不算数。」 |
| 杠杆型 | 5% | 1.20 | 高 | 0.92 | 券商 / 资管 / 银行 | 「杠杆是撬动世界的支点。」 |

### 随机性设计

1. **决策扰动** —— 每次决策在「性格基线 × 难度贪婪 × (1 ± 噪声)」上取值，
   噪声范围由难度决定（新手 0.50 / 普通 0.32 / 老手 0.18）。
2. **抽风** —— 小概率触发「梭哈」「追高被套」「突然清仓」。
3. **加仓重掷** —— 掷骰前基于资产排名与性格判断是否使用「打新/加仓」道具重掷一次。
4. **决策播报** —— 每次买/卖都会在回合日志里留下带性格的短台词。

### 难度

| 难度 | 决策准确率 | 噪声 | 贪婪 | 风险 |
|---|---|---|---|---|
| 新手 | 0.55 | 0.50 | 0.75 | 0.35 |
| 普通 | 0.75 | 0.32 | 1.00 | 0.50 |
| 老手 | 0.92 | 0.18 | 1.15 | 0.68 |

### 不作弊保证

`decide(state, player, decision, ctx)` 的签名**不接受骰子结果**。
自检里有一条专门断言：调用 `decide` 后返回对象中不含 `dice` / `total` 字段。

## 分享与社交

### 深链接

开局界面配置的 seed 与选项会编码进 URL：

```
?seed=xhzigf&mode=normal&ai=3&dice=2&cash=standard&mkt=normal&nick=测试员&av=0
```

打开链接即可复现同一局的地盘分布与 AI 性格。菜单 → `分享战绩` 可一键复制。

### 分享卡片

Canvas 生成的 480×300 PNG 分享图，包含：

- 标题、种子
- 四位玩家排名（资产 / 现金 / 控股机构数）
- 棋盘热力图（各格归属着色）
- 可下载 PNG 发朋友圈

### iframe 嵌入

菜单 → `分享战绩` → `复制嵌入代码`，得到：

```html
<iframe src="https://your-site/?seed=xxx&..." width="100%" height="720"
        style="border:2px solid #e0a53f;background:#161b2e;"
        allowfullscreen loading="lazy"></iframe>
```

### 本地战绩

`localStorage` 记录历史战绩、胜率统计与最长连锁记录；可在「菜单」中查看。

### 关键设计

**零外部资源。** 所有建筑、角色、图标、背景都是运行时用 Canvas 程序化绘制的，
仓库里没有任何 `.png` / `.svg` / `.mp3` 文件。调色板统一取自 `src/core/palette.js`
的 32 色。

**确定性随机。** 所有游戏内随机都走 `makeRng(seed)`（Mulberry32），
不使用 `Math.random()`，因此同一个 seed 必然复现同一局。

**纯函数经济层。** `economy.js` 里的 `calculateRent` / `upgradeCost` /
`mortgageValue` / `redeemFee` / `totalAssets` 全部无副作用，可直接单测。

**非节流调度器。** 浏览器会把后台标签页的 `setTimeout` 节流到最低 1 次/秒，
并暂停 `requestAnimationFrame`，导致回合流程在切走标签页后卡死。
`src/core/scheduler.js` 用 `MessageChannel` 绕开计时器队列，
保证游戏逻辑在后台也稳定推进（画面则由 RAF 负责，后台不刷新）。

**时间驱动的逐格动画。** `MoveAnimator` 基于 `performance.now()` 而非帧计数，
因此动画时长与帧率无关；同时带兜底截止时间，即使渲染循环被完全暂停也能收尾。
`MoveAnimator.frameState(rectOf, slotOf)` 会同时插值「目标格矩形」与「格内棋子槽位偏移」，
跳跃中的棋子与落位后的静态棋子使用同一套坐标计算，落位时零跳变、无视觉错位。

**升级许可作为状态而非 UI。** 「需再次踏足才能升级」不是弹窗层的判断，
而是写在 `state` 里的 `player.upgradePermits[cellIndex]` 标记：
踩到自有地块时由 `settleOnCell` 发放，`upgradeInstitution` 校验并消费。
这样 AI 与玩家走的是同一条路径，规则无法被绕过。

## 像素风实现要点

| 要求 | 实现 |
|---|---|
| 统一像素网格 | 所有精灵原生 16×16 / 32×32 / 16×24，渲染时整数倍放大 |
| 禁止非整数缩放 | `imageSmoothingEnabled = false` + CSS `image-rendering: pixelated` |
| 硬边缘无羽化 | 全部用 `fillRect` 绘制，不使用 `arc()` / `filter` / `blur` |
| 1px 描边 | `pixeldraw.js` 的 `outline()` 统一处理 |
| 三层体积感 | 色阶 + 高光 + 阴影三档，不用渐变 |
| 受限调色板 | `palette.js` 定义 32 色，所有绘制只能取用 |
| 离散帧动画 | 角色 4 帧行走、骰子翻滚帧、逐格跳跃 squash/stretch |
| 帧化 CSS 动画 | 所有 keyframes 以 `steps()` 离散变化 |
| 粒子用离屏精灵 | `effects.js` 用小 Canvas 批量绘制，不做 CSS 滤镜 |
| 昼夜四档 | 晨 / 午 / 黄昏 / 夜，切换天空色板 + 霓虹强度 |
| 背景视差 | 3 层天际线 + 像素云 + 出租车 + K 线灯带 + 交易所钟楼 |
| 音效 | WebAudio 合成方波/三角波 8-bit 音效，零音频文件 |

### 机构立绘的差异化

每家机构的建筑不是「同一栋楼换个颜色」，而是由 `cell.index` 派生的种子驱动，
组合出六条独立的变体轴：

| 变体轴 | 取值 | 表现 |
|---|---|---|
| `winCols` | 2 / 3 / 4 | 立面窗列数 |
| `bandStep` | 3 / 4 | 横向分隔带间距 |
| `roof` | flat / step / setback / spire | 屋顶造型（平顶 / 台阶 / 退台 / 尖顶） |
| `annex` | none / awning / wing / mast / vents | 附属构件（雨棚 / 侧翼 / 旗杆 / 机组） |
| `sign` | band / plate / box | 招牌样式 |
| `facade` | none / groove / belt / grid | 立面纹理（凹槽 / 腰线 / 网格） |

此外每栋建筑立面上会烙一枚 **3×3 像素指纹徽记**（9 位由种子决定的明暗格），
保证 45 家机构的精灵图两两不同 —— 自检项「机构立绘互不相同」会逐像素比对校验。

五大等级的高度阶梯为 `16 → 20 → 25 → 30 → 36` 像素，
地标级另起 `32×48` 的摩天体量，与普通机构一眼可辨。

## 常见问题

**Q：页面空白 / 游戏不初始化？**
检查浏览器控制台。若报 `Failed to fetch dynamically imported module`，
多半是某个 `.js` 的 MIME 类型不对 —— 请用 `python serve.py` 而不是直接双击
`index.html`（`file://` 协议不支持 ES Modules）。

**Q：首次加载很慢？**
请确认用的是 `serve.py` 而不是 `python -m http.server`。后者只监听 IPv4，
浏览器访问 `localhost` 时会先尝试 IPv6 并等待约 2 秒超时。
若必须用 `python -m http.server`，请改用 <http://127.0.0.1:8000/> 访问。

**Q：切到别的标签页，回来后游戏卡住了？**
不会。游戏逻辑使用 `src/core/scheduler.js` 的非节流调度器，
在后台也会继续推进；渲染由 RAF 负责，回到标签页即恢复画面。

**Q：怎么复现上一局？**
在分享弹窗里复制深链接，或手动把 `?seed=xxx` 加上其它参数。

**Q：手机能玩吗？**
可以。布局是响应式的，竖屏 / 横屏都做了适配，核心按钮支持触控。
