# 前端 3D 优化 —— 实施方案

> 五项前端优化的技术决策与拆分计划。所有决策已与用户确认。

## 一、决策汇总

| 项 | 选定方案 |
|---|---|
| 3D 技术路线 | **CSS 3D 变换** —— 保留 Canvas 2D 底层，DOM 层承担倾斜与视觉立体 |
| 旋转形态 | **固定 45° 俯视**，拖拽仅在平面内平移（不改观察角度） |
| 格子样式 | **保留 D+ 数据卡信息**，外观改成立体麻将牌（厚度 / 浮雕 / 边光） |
| hover 建筑 | **复用现有资源** —— `src/art/buildings.js` + `tiles.js` 的 `flatFacade` SVG |
| 角色立体化 | **2.5D** —— 现有 2D 立绘 + 落地阴影 + 立体牌位 + 呼吸光 |
| 文字可读性 | **反向补偿（billboard）** —— 信息层始终正对屏幕 |
| 3D 生效时机 | **默认平面 + 一键切换 3D** |
| 落地特效强度 | **轻量版** —— 椭圆阴影扩散 + 轻微上浮，不做粒子 |
| 拖拽边界 | **弹性回弹** —— 拖出边界回弹到原位 |
| PR 拆分 | **5 个独立 PR**，逐个可审查 |

## 二、现状架构（改造前基线）

```
#board-wrap                     ← 绝对定位容器，测量尺寸喂给 Canvas
├── #board-canvas               ← Canvas 2D：底板 / 护城河 / 中央广场 / 棋子 / 特效
├── #board-tiles                ← DOM 地块层（34 个 .mt-cell，百分比定位）
├── #fx-layer                   ← CSS 动画特效
├── #dice-tray / #toast-layer
└── #cell-detail
```

关键事实：

- **地块是 DOM 而非 Canvas** —— 文字由排版引擎处理，这是「地块可读性」的根基
- **Canvas 与 DOM 通过百分比对齐** —— canvas 尺寸变化时地块自动跟随，无需 JS 重排
- **`MoveAnimator` 已实现一格一跳** —— 每格 110ms + 落地压扁（`squash`）
- **角色是 2D 矢量立绘** —— 32×40，4 方向 × 2 帧
- **建筑资源已就绪** —— `buildings.js` 按等级递增高度（12/16/21/26/32 px）
- **当前深度方案是 `z-index: 3`** —— `.mt-cell:hover { z-index: 3 }`，3D 下必须替换为真实深度排序

## 三、核心难点：billboard 文字补偿

DOM 地块处于 `rotateX(45deg)` 的父容器中时，中文会被透视压扁成平行四边形。
地块上全是机构名、租金数字、等级刻度 —— 这些是玩法核心信息，**不能变形**。

补偿结构：

```html
<div class="mt-cell">              <!-- 承担 3D：倾斜、阴影、深度 -->
  <div class="mt-face">            <!-- 承担反向 rotateX(-45deg) 补偿 -->
    <div class="mt-content">…</div><!-- 文字层，最终正立 -->
  </div>
</div>
```

**固有代价**：反向补偿后牌面不再保持平行四边形，会有一边「翘起」的错位。
通过给牌面附加一点额外的 Y 轴微调，把错位压到最小。

## 四、PR 拆分

### PR-A · 3D 场景骨架

- `#board-wrap` 内新增 `#board-stage`（承载 3D 变换）+ `#board-pan`（承载拖拽平移）
- CSS `perspective` + `transform-style: preserve-3d`
- 3D 切换按钮（放入右上角资产排行面板，**不新增独立按钮位**）
- 拖拽平移 + 弹性回弹（平面模式下同样可用）
- Canvas 尺寸测量改为跟随 `#board-stage`（平移/倾斜不改变测量基准）

### PR-B · 立体麻将牌外观

- `.mt-tile` 增加厚度 / 浮雕 / 边光 / 底部投影
- 引入**真实深度排序**替代 `z-index: hover`
- 深色侧边（牌厚）用伪元素 `::after` 绘制

### PR-C · billboard 文字补偿

- 地块拆为 `.mt-cell` / `.mt-face` / `.mt-content` 三层
- `.mt-face` 反向 `rotateX` 抵消父级倾斜
- 可读性验证：45° 下机构名与租金数字必须清晰

### PR-D · hover 立体建筑浮现

- 复用 `buildings.js`（5 级高度）+ `flatFacade` SVG
- 透视投影 + 落地阴影
- 颜色 / 等级 / 持有者状态与格子信息严格匹配

### PR-E · 角色立体化 + 落地特效

- 2D 立绘 + 立体底座 + 落地呼吸光
- 落地特效：椭圆阴影扩散 + 轻微上浮（轻量版，无粒子）
- 倾斜下的投影方向修正

## 五、实施约束

- **零构建** —— 纯静态 ES Modules，不引入 Three.js 等依赖
- **规则层零改动** —— `src/core/*` 全部不动，只碰渲染与样式层
- **可读性硬标准** —— 零文字裁切；45° 下中文仍须可读
- **左右两列不变** —— HUD 左竖栏 / 右侧排行面板的功能与布局保持现状
- **整体设计风格不变** —— D+ 现代数据卡的配色、语义、版式语义全部保留
